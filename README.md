# Aadhaar Insight – Streamlit Dashboard

This repository contains a **Streamlit** application that visualises Aadhaar enrollment, demographic, and biometric statistics.

## Files
- `app.py` – Main Streamlit app.
- `requirements.txt` – Python dependencies (including **plotly**).
- `.streamlit/config.toml` – Streamlit config for headless deployment.
- `README.md` – This file.

## Quick start (local)
```bash
# Create a virtual environment and install deps
python -m venv .venv
source .venv/bin/activate  # on Windows: .venv\Scripts\activate
pip install -r requirements.txt
streamlit run app.py
```

## Deploying to Streamlit Cloud
1. Push the repository to GitHub (already done).
2. In Streamlit Cloud, create a new app and link it to this repo.
3. The platform will automatically run `pip install -r requirements.txt` and launch `app.py`.
